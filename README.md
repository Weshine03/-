# 摹寫升級器｜摹寫探險隊
> **一步一步，把感受寫得更清楚**  
> 專為國小三年級學童設計的形成性摹寫學習與輔助引導系統

---

## 🌟 產品定位與教學目標

「摹寫升級器」是一套結合 20 年國語文教學經驗與形成性引導理念的互動網頁 App。它**不是**代寫工具，也不是冷冰冰的自動打分機，而是一位溫暖、耐心的探險導師，陪伴國小三年級學童（約 8-9 歲）經歷：
$$\text{觀察} \longrightarrow \text{自己寫} \longrightarrow \text{評估} \longrightarrow \text{引導} \longrightarrow \text{自己修改} \longrightarrow \text{再評估} \longrightarrow \text{通關}$$

### 核心教學原則
1. **學生是句子的作者，AI 是引導者**：絕不替學生代寫或改寫整句。
2. **最高規則：不直接給答案**：
   - 作答前不顯示「快速靈感」、「參考佳句」或形容詞詞庫。
   - 不提供可點選直接插入句子的答案按鈕。
   - 詞語小百科僅在第一次提交後做為非強制的參考工具箱。
3. **客觀文字證據**：五項規準均要求引用學生實際寫出的字詞，杜絕虛構評價。
4. **包容與真實**：
   - 簡短清楚的句子（如「小狗搖著尾巴。」）也是優秀的摹寫。
   - 動詞往往比空泛形容詞更能呈現摹寫的生動特質。
   - 區分圖片視覺觀察與學童生活感官經驗（如食物的溫度或香氣）。
5. **達標即通關，絕不強迫修改**：
   - 4 顆星即通關並頒發印章，解鎖下一關。
   - 5 顆星榮獲滿星大師成就；一開始達標即如實肯定，不虛構進步。

## 📐 五顆星摹寫評分規準

每項標準得分只能為 **0 分** 或 **1 分**，由伺服器獨立驗證與加總（總分 0-5 分）：

| 規準名稱 | 評估標準 | 給分原則 |
| :--- | :--- | :--- |
| **1. 描寫對象明確** | 讀者能辨認描寫的主體 | 直接出現或可由情境清楚推斷；不因省略主語扣分 |
| **2. 具有具體特徵** | 至少呈現一項外觀、動作、形狀、聲音、氣味、味道或觸感 | 動詞、名詞或具體事件皆可；不強求全用形容詞 |
| **3. 詞語選用精確** | 用詞符合對象與情境，意思清楚明白 | 不因詞語簡單扣分，不以華麗為標準 |
| **4. 描寫細節豐富** | 提供相關細節讓讀者容易想像 | 不以字數長短判斷；不將重複形容詞計為多項細節 |
| **5. 生動且有特色** | 呈現值得注意的細微觀察、具體動作或真切感受 | 不強制比喻或擬人，以三年級生活語言為準 |

## 🪜 四階梯提示鷹架（逐步降低難度）

當學童未達 4 星通關時，系統每次**只提出一個問題**，並依循四階梯逐步支持：
- **Level 1 開放式問題**：例如「你還觀察到了什麼？」
- **Level 2 具體觀察方向**：例如「你可以再看看花瓣的邊緣，你注意到什麼樣子？」
- **Level 3 少量選項思考**：例如「想一想：可以觀察它的顏色深淺、形狀，還是上面的小水珠？」
- **Level 4 空白句型開頭**：例如「我注意到＿＿＿＿。」（不填入答案）
- **防卡關關懷**：學童表示不知道或連續卡關時，主動提供「再觀察一次」、「休息一下」或「舉手請老師幫忙」。

## 🔒 資料安全性與隱私規範

- **本機保存範圍**：學生練習紀錄、修改歷程與通關印章均保存在當前電腦／平板之瀏覽器（`localStorage`）。
- **無隱私洩漏**：不要求學生登入，不建置未經說明的跨裝置雲端資料庫。
- **教師專業備份**：教師可隨時透過「教師管理」專區，將本機所有紀錄手動匯出為標準 JSON 備份檔。
- **Gemini API 金鑰安全**：API 金鑰僅存於後端環境變數，絕不傳送到前端瀏覽器。

## 🛠️ 教師功能與評分校準測試

1. **關卡任務管理**：新增、編輯與刪除主題，設定簡單中性的觀察題目與圖片。
2. **歷程檢視與覆核**：
   - 檢視學童第一次寫作與歷次修改。
   - 查驗五項規準的文字證據與判定理由。
   - **教師覆核調分**：教師可手動修正 AI 初評分數並填寫教學筆記，系統同步保留原始 AI 分數與教師覆核紀錄。
3. **15 項核心情境校準測試**：
   涵蓋簡短句子、具體動作無形容詞、詞語包容性、經驗判定、防重複點擊、斷線保留及格式安全。

## 🚀 安裝與啟動指引

### 1. 取得專案與環境準備
確保您的環境已安裝 Node.js (v18+) 與 npm。

```bash
# 複製專案後進入目錄
npm install
```

### 2. 設定環境變數
在專案根目錄確認 `.env` 檔案設定有 Gemini API 金鑰：

```env
GEMINI_API_KEY="您的_GEMINI_API_KEY"
PORT=3000
```

### 3. 本地開發模式啟動
```bash
npm run dev
```
啟動後開啟瀏覽器造訪：`http://localhost:3000`

### 4. 執行評分規準自動化測試
```bash
npm test
```

### 5. 生產環境建置與運行
```bash
npm run build
npm start
```
